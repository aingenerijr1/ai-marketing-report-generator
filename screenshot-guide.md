# Screenshot Guide

## Purpose
This file explains the screenshots included in the AI Marketing Performance Report Generator project.

The screenshots provide visual evidence of the spreadsheet prototype, reporting logic, AI prompt structure, validation checks, and sample report output.

## Screenshot Files

### `01-raw-data.png`
Shows the `Raw Data` tab.

This screenshot includes the sample weekly marketing performance data used by the project, including users, sessions, engagement rate, conversions, CTA clicks, top channel, top page, and notes.

### `02-weekly-comparison.png`
Shows the `Weekly Comparison` tab.

This screenshot demonstrates how the spreadsheet compares previous week and current week performance. It includes metric values, numeric changes, percent changes, key insight, and potential recommendation.

### `03-ai-prompt-input.png`
Shows the `AI Prompt Input` tab.

This screenshot shows the dynamic prompt lines that turn spreadsheet values into marketing-friendly language. It also shows validation checks, warning notes, final review status, and the final prompt block that could later be sent to an AI model.

### `04-generated-report.png`
Shows the `Generated Report` tab.

This screenshot shows a sample marketing performance report output. The sample report demonstrates what the final AI-generated report should eventually look like after automation is added.

### `05-notes-progress-log.png`
Shows the `Notes` tab.

This screenshot shows project progress notes, JSON practice, Day 1 through Day 3 build notes, and formula debugging documentation.
