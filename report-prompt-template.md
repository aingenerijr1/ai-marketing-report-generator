# Report Prompt Template

## Purpose
This prompt template is designed to generate a weekly marketing performance report from structured campaign or website performance data.

## Prompt

Generate a weekly marketing performance summary using the data below.

Focus on:
- Key metric changes
- Business meaning
- Possible causes or patterns
- Recommended next actions

Use the following report structure:

## Executive Summary
Summarize the overall performance trend in 2-3 sentences.

## Key Metric Changes
Explain the most important metric changes, including users, sessions, engagement rate, conversions, and CTA clicks.

## Business Interpretation
Explain what the changes may mean from a marketing or website performance perspective.

## Recommended Next Actions
Provide 2-3 practical recommendations based on the data.
